# Sci‑Fi World Dithered Images Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Render all in-app UI images as dithered (SmoothUI `DitherImage`, `algorithm="threshold"`, `levels={2}`) only when style world is `scifi`, with palette aligned to scifi primary, while keeping print/receipt outputs normal and QR/barcode surfaces crisp.

**Architecture:** Install SmoothUI `dither-image`, add a client `AppImage` wrapper that switches between normal `<img>`/`next/image` and `DitherImage` based on `useStyleWorld()` and a `crisp` opt-out, then refactor in-app JSX `<img>`/`next/image` usages to `AppImage` (excluding print/receipt HTML string generators). Palette fixed to scifi tokens `["#061108","#4fdc68"]`.

**Tech Stack:** Next.js 16 (App Router), React 19, TypeScript, Tailwind/shadcn project, `next/image`, SmoothUI `@smoothui` registry (`components.json`), `StyleWorldProvider`/`useStyleWorld` (`src/lib/style-world-context.tsx`).

**Spec:** `docs/superpowers/specs/2026-11-16-scifi-dither-images-design.md`

## Global Constraints

- Dither only when `world === "scifi"`; other worlds unchanged.
- Preset: `algorithm="threshold"` and `levels={2}`.
- Palette must follow scifi primary: `["#061108", "#4fdc68"]` (canvas, primary).
- **Do not** modify print/receipt/thermal **HTML string** outputs (`src/components/print-templates.tsx`, `src/lib/sales/receipt.ts`, `src/components/cash/shift-thermal-print.tsx`) — keep plain `<img>` in generated HTML.
- QR/barcode surfaces must remain crisp/scannable in scifi (use `crisp`/disable-dither opt-out).
- Preserve existing image behavior/layout/props as much as possible; prefer smallest safe diff.

## Review Focus

- **CORS-tainted remote images in scifi:** canvas dithering may fail to draw cross-origin images without proper CORS; expected behavior is a safe fallback to normal image (not a crash/blank UI).
- **`next/image`-only props (`fill`, `sizes`, `priority`, `unoptimized`) in scifi:** `DitherImage` API may differ; wrapper must still render correctly sized/positioned image without layout break.
- **Accidental dithering of print/receipt output:** generated print HTML must still contain normal `<img>` tags and render clearly (no canvas-only component in string templates).
- **QR/barcode crispness:** any in-app QR/barcode render marked/kept crisp must not be processed by `DitherImage` in scifi.
- **Non-scifi regression:** in `minimal`/`toy`/`craft` worlds images must render exactly as before (no dither, no prop loss).
